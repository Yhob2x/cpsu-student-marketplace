# P2 marketplace UX polish — 17 November 2026

The mobile Home page now places Fresh listings immediately after the hero, ahead of the install promotion. Explore puts its existing swipe/drag cue and previous/next controls before the result grid, while keeping the shared two-row scroll surface.

The seller composer previews valid selected local images. A new listing uploads its chosen cover first, using the existing sequential single-photo API. Editing shows existing and newly selected photos together as cover choices. A new, owner-only `PATCH /seller/listings/:id/media/cover` action changes the cover after upload, normalizes positions transactionally, and audits the change. It accepts only an attached photo on an editable, nondeleted, unreserved listing. Existing approved photos can be reordered without adding new content; any newly uploaded photo still returns a published listing to draft for campus review. Partial-upload and cover failures are reported as partial success, preserving the saved listing and its remaining retry path. No schema change or migration was needed.

Notifications now show unread summary and feed before a collapsed Notification preferences section. Unknown routes show a Page not found screen with Home and Explore paths. Sign-in and registration show associated field errors for native validation and known server codes, mark invalid fields, and focus the relevant field after server responses; general failures remain form alerts. Backend validation remains authoritative.

Verification: web TypeScript and Vite production build, full web tests, API TypeScript, synthetic cover HTTP tests (owner, guest, staff, foreign photo, locked state, malformed request and modeled audit rollback), and headless Chrome at 320/390 px for Home ordering, Explore cue placement, unknown route, and invalid-field focus. The cover HTTP suite uses synthetic rows; an isolated MySQL integration and physical iPhone/Android acceptance are still required before release. No development or production database was modified by this work.
