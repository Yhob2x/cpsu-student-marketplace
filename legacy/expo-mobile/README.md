# Inactive Expo prototype — preserved local source

This folder is an **archive**, not an active application. On 12 November 2026 the CPSU Student Marketplace was consolidated into the responsive web/PWA in `apps/web`, as directed by the project owner.

The folder was moved from `apps/mobile` without deleting its local edited files, so earlier prototype work remains available for historical reference or a future explicitly approved native-app project.

- Not part of the root `workspaces`.
- No `npm run mobile` or `bun run mobile` startup command exists.
- Not deployed, installed or tested as the current mobile marketplace.
- Do not modify `app.json` or configure `extra.apiUrl` for the unified web app. The active frontend uses relative `/api/v1` URLs.
- Do not merge native-only session or UI code into the responsive web app without a reviewed plan.

See `README.md` and `docs/UNIFIED_WEB_PWA_2026-11-12.md` for the current single-frontend architecture.
