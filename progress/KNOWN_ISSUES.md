# Known issues

**Platform update (12 November 2026):** The mobile/desktop frontend is now the same responsive web/PWA (`apps/web`). Expo and its original source are archived under `legacy/expo-mobile`; there is no active mobile startup command. See `docs/UNIFIED_WEB_PWA_2026-11-12.md`. The remaining physical-phone and assistive-technology release gates still apply.

Severity: **critical** blocks MVP or security · **high** blocks launch readiness · **medium** degrades a required feature · **low** hygiene.
Status: open unless stated. Fixes belong to the work packages in `docs/MVP_SCOPE.md` §5.
